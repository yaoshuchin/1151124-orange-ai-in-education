# 🍊 Ai在教學上的應用 - 橘子老師實戰講座 數位學習平台

> 橘子老師主講：AI在教學上的應用 · 5大核心落地實戰 · 完整52頁高清教材與自動化工作流

---

## 🌟 平台特色

- **密碼保護閘門**：通行密碼設定為 `nato`，保護研習教材與教學檔案安全存取。
- **即時視覺控制**：
  - **字型切換**：`中` (標準)、`大` (放大)、`特大` (超大)，便於投影與長者閱讀。
  - **四色布景切換**：`淺` (清新手帳橘)、`深` (夜間極客黑)、`綠` (森林護眼綠)、`藍` (科技專業藍)。
- **分頁分類標籤**：
  1. 📌 **全部總覽 (52 頁)**
  2. 👤 **課程導言 (4 頁)**：講師介紹與橘子老師社群專頁。
  3. 🎙️ **語音辨識與會議記錄 (13 頁)**：行政會報 MP3 轉文字、講者辨識、自訂 SKILL.md。
  4. 🎮 **課程複習射擊遊戲 (8 頁)**：課本 PDF 自動生成 HTML5 單人與雙人對戰射擊遊戲。
  5. 📚 **雲端繪本生成器 (19 頁)**：皮克斯風格 3D 繪本、角色外觀一致性錨定、排程自動產出。
  6. 📝 **會考出題大師 (8 頁)**：截圖一鍵召喚 AI 進行素養導向命題、難度梯度與詳解解析。
  7. 📦 **教學資源下載總庫 (12 組)**：全套 Google 雲端硬碟檔案、語音素材、SKILL 安裝包。
  8. 💡 **實戰提示詞指令庫**：一鍵複製可直接貼入 Gemini / NotebookLM / Antigravity 執行。
- **全螢幕簡報播放器**：支援鍵盤左右方向鍵切換頁面、ESC 退出、高清圖片燈箱。
